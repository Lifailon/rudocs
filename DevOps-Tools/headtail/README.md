## HeadTail

Реализация двух утилит командной строки (`head` и `tail`) в одной на Go.

```Bash
# Доступные параметры:
# -p, --path   - путь к файлу
# -l, --lines  - количество строк для отображения
# -h, --head   - выводить строки с начала файла (по умолчанию с конца)
# -f, --follow - отслеживать изменения в файле

# Вывод первых 5-ти строк:
go run main.go -p /etc/ssh/sshd_config -l 5 -h

# Вывод последних 5-ти строк в режиме следования:
go run main.go -p /var/log -l 5 -f
```
