## Filter

Инструмент командной строки для фильтрации стандартного потока ввода.

Поддерживает два режима работы:

- **Contains** (*по умолчанию*) - ищет все переданные слова через пробел в каждой строке
- **Regex** (аргумент `-r/--regex`) - поддержка регулярных выражений, как в `grep`.

Другие доступные аргументы командной строки:

- `-i/--igonre-case` - учитывать регистр
- `-n/--no-color` - отключает встроенную покраску найденных паттернов
